# ShortID SDK 功能总结

## 📋 核心功能

ShortID SDK 提供了三个核心功能：

### 1. 分布式全局唯一ID生成
- 支持业务类型标识
- 支持机器ID（分布式部署）
- 支持时间戳编码（日期或完整时间戳）
- 支持序列号（同一秒内递增）
- 支持同时生成字符串ID和数字ID（Base10格式，类似雪花ID）

### 2. Base62 编码字符串
- 数字到Base62字符串的转换
- Base62字符串到数字的反向转换
- URL安全，可直接用于URL

### 3. 时间戳和日期编码
- 时间戳压缩编码（短编码、动态编码、紧凑编码）
- 日期编码（年月日到短字符串）
- 支持多种编码模式

---

## 🚀 快速API（Quick Functions）

### 基础编码
- ID编码：将数字ID转换为Base62短字符串
- 时间戳编码：将时间戳压缩为短字符串
- 日期编码：将年月日编码为短字符串

### 业务场景快速生成
- 订单ID：快速生成订单标识符
- 分享码：生成带有效期的分享码（如7天有效）
- 邀请码：生成邀请码
- 缓存键：生成带时间戳的缓存键

### 批量生成
- 批量订单ID：一次性生成多个订单ID
- 批量用户ID：一次性生成多个用户ID
- 批量分享码：一次性生成多个分享码

---

## 🔧 高级API（Advanced API）

### ID生成器（IDGenerator）
- 创建自定义ID生成器，支持配置业务类型、日期编码、机器ID、前缀等
- 生成ID：生成字符串格式的ID
- 同时生成字符串ID和数字ID（Base10格式）
- 解析ID：解析ID获取业务类型、时间戳、序列号等信息

### 预设生成器（Presets）
- 默认订单生成器：预配置的订单ID生成器
- 默认用户生成器：预配置的用户ID生成器
- 默认分享码生成器：预配置的分享码生成器

### 时间戳编码器（TimestampEncoder）
- 创建时间戳编码器，支持天数模式、紧凑模式等配置
- 编码时间戳：将时间戳压缩为短字符串
- 解码时间戳：将短字符串还原为时间戳

### 简单编码器（SimpleEncoder）
- ID编码/解码：数字ID与Base62字符串互转
- 时间戳编码/解码：时间戳与短字符串互转
- 日期编码：将年月日编码为短字符串

---

## 💡 应用场景

### 1. 电商系统
- **订单ID**：为每个订单生成唯一标识符，便于追踪和管理
- **支付流水**：为支付交易生成唯一流水号，支持财务对账
- **物流单号**：生成物流跟踪单号，支持物流状态查询

### 2. 社交应用
- **会话ID**：为临时会话生成唯一标识，支持会话管理
- **动态ID**：为社交动态生成唯一ID，便于内容管理
- **评论ID**：为评论生成唯一标识，支持评论系统

### 3. 营销活动
- **优惠券码**：生成优惠券兑换码，支持有效期管理
- **促销码**：为促销活动生成唯一码，支持活动追踪
- **活动码**：为营销活动生成参与码，支持活动管理

### 4. 短链接服务（参考TinyURL）
* [tinyurl](https://tinyurl.com/)

短链接服务是ShortID SDK的核心应用场景之一，类似于TinyURL的功能：

#### 核心功能需求
- **URL缩短**：将长URL转换为短小精悍的短链接
  - 输入长URL，自动生成短链接（如 `https://tinyurl.com/38d37svt`）
  - 短链接长度4-10字符，便于分享和记忆
  - 支持自定义短链接后缀（可选）

- **QR码生成**：为短链接生成对应的QR码
  - 支持一键生成QR码
  - QR码可用于线下推广和分享

- **链接分享**：便捷的分享功能
  - 支持多种分享方式
  - 一键复制短链接

- **链接管理**：记录和管理生成的短链接
  - 显示最近生成的链接列表
  - 支持查看原始长URL
  - 支持访问统计（付费功能）

- **链接访问**：通过短链接访问原始URL
  - 短链接自动跳转到原始长URL
  - 支持访问记录和统计

#### 高级功能（付费功能）
- **品牌化域名**：使用自定义域名生成短链接
  - 支持绑定自有域名
  - 提升品牌形象和信任度

- **链接分析**：详细的访问数据分析
  - 访问次数统计
  - 访问来源分析
  - 访问时间分布
  - 地理位置分析

#### 应用场景
- **商品分享链接**：电商平台生成商品短链接，便于社交媒体分享
- **活动报名链接**：营销活动生成报名短链接，便于传播和统计
- **限时优惠链接**：促销活动生成优惠短链接，支持时效性管理 + 有效期
- **内容分享链接**：内容平台生成文章/视频短链接，便于分享和传播

## 📊 ID格式说明

### 字符串ID格式

```
[Prefix] + BusinessType + TimePart + [MachineID] + [Sequence]
```

**各部分说明**：

| 部分 | 长度 | 表示范围 | 说明 |
|------|------|----------|------|
| **Prefix** | 可变 | 自定义 | 可选前缀，由用户自定义（如 "ORDER"） |
| **BusinessType** | 1字符 | 0-9, A-Z (62种) | 业务类型标识符，Base62编码 |
| **TimePart** | 3字符或6字符 | 根据模式不同 | 时间部分，根据编码模式不同：<br>- **日期编码模式**（EnableDate=true）：**固定3字符**<br>  - 表示范围：0 到 238327 天（62³-1）<br>  - 相对基准日期（2020-01-01）的天数差，Base62编码<br>  - 时间范围：2020-01-01 到 约2672年（约652年）<br>- **时间戳编码模式**（EnableDate=false）：**固定长度**<br>  - **使用基准日期（2020-01-01）优化**：<br>    - 4字符：0 到 14776335 秒（62⁴-1），时间范围：约0.5年（不推荐）<br>    - 5字符：0 到 916132831 秒（62⁵-1），时间范围：2020-01-01 到 约2049年（约29年）<br>    - 6字符：0 到 56800235583 秒（62⁶-1），时间范围：2020-01-01 到 约3820年（约1800年）<br>  - **理论分析**：<br>    - 覆盖到2100年（80年）需要约25亿秒，5字符不够，需6字符<br>    - 覆盖到2050年（30年）需要约9.5亿秒，5字符足够<br>    - 6字符可覆盖约1800年，远超一般业务需求<br>  - 相对基准时间（2020-01-01）的时间戳偏移，Base62编码 |
| **MachineID** | 1-2字符 | 0-1023 | 可选，机器ID，Base62编码，支持1024台机器 |
| **Sequence** | 3-4字符 | 根据长度不同 | 可选，序列号，Base62编码：<br>- **3字符**：0 到 238327（62³-1）<br>  - 理论QPS：238,328/秒<br>  - 实际使用：通常限制为5000 QPS（足够大多数场景）<br>- **4字符**：0 到 14776335（62⁴-1）<br>  - 理论QPS：14,776,336/秒<br>  - 适合超高并发场景（千万级QPS） |

**示例**：
- `35E03d7` - 订单ID（业务类型3，日期编码5E0固定3字符，序列号3d7固定3字符）
- `2bx0001` - 用户ID（业务类型2，日期编码bx0固定3字符，序列号001固定3字符）
- `A5L03d7` - 分享链接（业务类型A，日期编码5L0固定3字符，序列号3d7固定3字符）
- `Bp` - 邀请码（业务类型B，用户ID编码p，特殊格式，总长度2字符）

### 数字ID格式（Base10，类似雪花ID）

```
64位 = 1位符号(0) + 41位时间戳(秒) + 8位业务类型 + 10位机器ID + 4位序列号
```

**示例**：
- `1734365478123456` - 对应的Base10数字ID

## ⚡ 性能特点

- **高性能**：单实例支持100万+ QPS
- **低延迟**：平均延迟 < 1μs
- **短小精悍**：ID长度4-10字符，比雪花ID（19位）和UUID（36字符）更短
- **URL友好**：Base62编码，可直接用于URL
- **可解析**：ID包含时间戳和序列号信息，可解析
- **分布式支持**：通过机器ID区分不同实例
  - **传统部署模式**：通过环境变量或配置文件设置固定的机器ID
  - **无服务器模式**（Lambda/Serverless）：通过Redis动态获取和分配机器ID
    - 每次Lambda函数启动时，从Redis获取或分配一个唯一的机器ID
    - 使用Redis的原子操作（如INCR）确保机器ID的唯一性
    - 支持自动过期和回收，适合动态扩缩容场景
    - 示例：`machineID := redis.INCR("shortid:machine:id") % 1024`
