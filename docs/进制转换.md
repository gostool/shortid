# 任意进制转换

* django.core.singning.b62_encode
* https://github.com/pyhuo/bases

```python
import time

from django.core.signing import b62_encode, b62_decode

def main():
    s = b62_encode(int(time.time()))
    print(s)
    print(b62_decode(s))
    pass

if __name__ == '__main__':
    main()
```
